# Claude Skills

A collection of [Claude skills](https://docs.claude.com/en/docs/agents-and-tools/agent-skills/overview).

## Skills

| Skill | What it does |
| --- | --- |
| [learn-before-task](Learn-before-task/) | Gives a short "learn first" brief before a task, and a debrief after. |

## Install

```bash
git clone https://github.com/mnamnam/Claude-Skills.git
```

Then follow the README inside each skill folder.
